Scanning a tag opens the matching Elation patient chart. This page is only for authorizing the reader and writing tags; the reader keeps running in the background when the page is closed.

Not connected

01 / Connection

JADAK USB serial

Authorize once in Chrome. The extension then holds the reader open in the background and reconnects automatically.

02 / Read

Tag controls

Automatic block 4 read

Always on while connected. Block 4 holds the patient id, and a scan opens app.elationemr.com/patient/<id> in the active Elation tab.

Write application data

Writes exactly 16 bytes to block 4 of the tag presented within 10 seconds.

This overwrites the current contents of block 4. Keep only one tag near the reader.
